# HyLogger Explorer: project page

This branch holds the GitHub Pages site at
<https://nhuannguyen87.github.io/hackathon_hylogger/>. The app's code is on the
[`main`](https://github.com/nhuannguyen87/hackathon_hylogger/tree/main) branch.

The page is static and holds no HyLogger data. Its pictures are the screenshots
already in `docs/screenshots` on `main`, resized, plus one close-up of
`compare-3d.jpg` and a link-preview crop (`og.jpg`).

To change the page, edit `index.html` on this branch and push; GitHub Pages
republishes it within a minute or two.
